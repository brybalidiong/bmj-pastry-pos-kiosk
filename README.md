# BMJ Pastry POS

See [IMAGE-ASSETS.md](IMAGE-ASSETS.md) for product photograph paths, missing-file
inventory, neutral image fallback behavior, and its browser tests.

Browser-local HTML/CSS/JavaScript pastry kiosk prototype with a functional cart, order review, simulated cash/card/QR payments, inventory finalization, and digital receipts.

See [PAYMENT-FLOW.md](PAYMENT-FLOW.md) for setup, architecture, simulation behavior, QR details, and tests. No real payment gateway or backend is used.

The existing visual design uses Poppins, navy #1D3461, pale #f4f7fb, rounded white cards, and restrained shadows. Payment integration preserves the existing layouts and design.
